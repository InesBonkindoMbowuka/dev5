Streetlight Surveillance Simulator Game 

A web-based surveillance simulation game where smart streetlights track pedestrians throughout a neighborhood. The player analyzes the collected detection data and pedestrian behavior to identify the burglar and make the correct accusation. 

Technologies used 
- Vue
- Node
- Express
- Mongodb 
- Docker / Docker Compose 

Required to run
- Git
- Node.js
- Docker desktop

How to install
- clone repository
- open folder :cd dev5
- Create a `.env` file based on `.env.template`file and copy the required environment variables.
- build using command in terminal: docker compose up --build
- open app in browser via the frontend link. Example: http://localhost:5173/
