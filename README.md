Streetlight Surveillance Simulator Game 

This project is a simulation game where the player needs to figure out who the burglar is based on behaviors detected by the neighborhood streetlights. 

Technologies used 
- Vue
- Node
- Express
- Mongodb 
- Docker / Docker Compose 

Required to run
- Git
- Node.js
- Docker desktop

How to install
- clone repo
- opne folder :cd dev5
- Create a `.env` file based on `.env.template` and add the required environment variables.
- build using command in terminal: docker compose up --build
- in a new terminal start backend with: cd backend -> npm install -> npm run dev 
- in a new terminal start frontend with: cd frontend ->npm install ->  npm run dev
- open app in browser via the frontend link. Example: http://localhost:5173/
